# HUD 动效设计

参考：[UX is Fine — Motion Services](https://www.uxisfine.com/motion-services)。用户指定主要采用 **HUD elements that guide & stabilize** 一段的视觉语言。读取页面八段原视频并按时间序列检查完整镜头；主要 HUD 切换另以每秒八帧检查 6.4–9.4 秒的过渡。参考视频只保存在忽略目录用于分析，不随项目分发。

## 从视频提取的节奏

- HUD 示例（12.08 秒）：0–2 秒先出现空间主题和导航，再展开辅助信息；2–5 秒卡片按层级出现，选中框和细规则线建立焦点；6.4–7.6 秒旧内容退场，空间图形接替；7.6–10 秒结构线先建立，三角节点再逐批点亮。保留这种有先后的展开，不复制星球、技能树美术或平面排版。
- 顶部技能树视频（12.08 秒）与 HUD 使用相近内容，强调深色空间、低对比结构线和局部清晰焦点。
- Rhythm（11.57 秒）与 Stingers（18.25 秒）：借鉴标题、细线与后续信息的出现顺序；快速全屏擦拭与强烈闪动不用于本 VR 游戏。
- Prototypes（88.43 秒）：同一空间中不同信息层有各自的退出/进入时间，确认反馈短于浏览过渡。
- UI Elements（15.45 秒）：边框、填充、确认符号分工明确，点击必须有可见回应。
- Make it Memorable（40.62 秒）是多类实例汇编；末尾图像循环（18 秒）以局部次级运动维持生命感。

## 游戏中的应用

补充实现参考：[ak-ui 按钮](https://github.com/YunYouJun/ak-ui/blob/master/src/scss/_ak-button.scss)、[motion tokens](https://github.com/YunYouJun/ak-ui/blob/master/src/scss/_tokens.scss)、[动效说明](https://github.com/YunYouJun/ak-ui/blob/master/skills/ak-ui/references/motion.md)，核对版本 `ae5d2bd310844f9a75e3130c2055ea0f805caa86`。其 120/200/420ms 反馈分级、悬停窄光带与菜单错峰可用于这里的节奏；二维 translate/scale 转译成沿面板法线的真实位移、侧面厚度和按压凹陷。代码为原生 Kotlin/GLES 实现，不引入网页运行时。

1. 掌心面板先显露边框与底板，再展开按钮；收起保留短暂淡出。
2. 关卡路线按真实依赖从下向上展开；移动结束后分出辨认与运动两列。连接线先建立，节点逐层出现，翻动六层视窗时先收旧内容再展新内容；选中状态通过深度与细线强调。
3. 按钮拥有抬升、按压和短回落，焦点线与扫光在 GPU 上运行。视觉位移不改变手指接触平面。
4. 教学字幕、关卡信息与完成状态分层过渡，角度条前沿连续响应，阅读内容保持稳定。
5. 世界中当前可见的目标与路标具有低幅浮动标记、路径亮点和局部确认展开。真正的四维截面、碰撞与教学几何不为装饰动画而缩放或平移。

## 实现约束

- 每帧改变 quad 变换和预乘 alpha；静态文字图集仍按状态更新，最多约 10 次/秒，不以整图重画实现平滑动画。
- 世界标记使用独立半透明三角形缓冲，受实体遮挡、不写入深度，不重建整个碰撞场景。
- 输入交互与视觉状态分开：切页未就绪时不接受旧页面的手指点按；键盘快捷键仍可操作。
- 动效尊重失焦暂停，快速换页与显隐反转连续处理；不对头显视角施加摇晃或转动。
- 基线提交：`7a5fd47`。后续功能提交独立保留，可通过 Git revert 撤销。

## 路线节点细节

编号与章名位于纸白头带，关名位于炭灰主体；选中节点使用浅色面，保留暖黄色焦点和橙色当前位置短线。完成、可进入与锁定状态使用独立矢量符号，锁定连接采用短虚线。面板与按钮采用轻微切角、细内边缘、低对比斜纹和上边高光，继续通过真实侧面和法线位移表现空间厚度。

地图、解锁和输入共用依赖图与节点矩形。视觉连线仅约简传递冗余，真实前置关卡门槛不简化；这保证旧存档缺少早期完成记录时，也不会由一条较短的显示连线错误解锁后续关卡。

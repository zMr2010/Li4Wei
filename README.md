## 四维几何与移动

世界坐标为 `(X,Y,Z,W)`。唯一的角度 θ 决定切片水平方向，Z 为重力方向、W 保持不变：

```text
Bθ(s,z,w) = (s cosθ, s sinθ, z, w)
world(q) = origin + Bθq
旋转时：origin' = world(q玩家) − Bθ' q玩家
```

画面是四维物体与当前三维超平面的**真实相交**。盒体用八个半空间求凸截面；超球截面半径为 `sqrt(R²−d²)`。不与切片相交的物体不可见，不显示完整四维投影或离面幽灵标记。旗帜、路标 glyph 仅标注已存在的真实截面；地面网格是观察者的参考。

原生入口 `vr/OpenXrActivity` 使用运行时预测双眼视图与真实 6DoF，OPAQUE 合成覆盖整个视野，不启动默认房间。系统安全边界仍由运行时管理。头部转动改变视角，不改变 θ。现实走动、键盘/手柄移动都经过胶囊体连续碰撞；撞墙时抵消本帧被拒绝的位移，不累积退回距离，稍微后退就能离开墙。保留原始双眼、头手相对位置和自然眼高；没有人工跳跃或飞行。

**辨认章 2-1–2-3 的实际观察固定虚拟位置**，保留转头与 θ；三关几何讲解仍能自由走动观察。**运动章 3-1–3-3 的讲解及实际观察均允许移动**，包括现实走动和 WASD。实际阶段以初始切片方向比较运动；转动到其他方向仍可探索，但不能用恒定不变的截面或离开物体后的计时替代对应观察。完成后也可继续走动观察，再按 N 前进。

## 运动与关卡规则

运动对象在四维空间中平移，大小和方向保持不变；屏幕中截面的大小、位置、棱数变化均来自真实相交。球体及两种盒体以 12 秒周期往返。正穿球只有隐藏方向位移；斜穿球增加水平位移；倾斜盒体依次呈现三棱柱、六棱柱、三棱柱，细长盒体同时展示另一种稳定形状的移动截面。

实际观察会检查入口、中央和出口阶段的真实截面特征，并要求短暂连续观察；只等待时间、把球转成始终位于切片内、或走到看不见它的位置，都不会自动完成这三个观察阶段。观察完成后保存进度，N 进入下一关。

移动挑战的建筑在 X/Y/Z/W 八个方向有重叠边界，不能从关卡外绕行。路标必须由玩家实际到达并与切片相交，完成条件不是指定角度口令。H 或掌心「提示」分三级给出观察线索、方向线索和具体走法；默认只显示当前任务。

T 或「返回路标」回到最近实际到达的脚部位置与 θ；运动挑战还恢复当时的运动时间。选择同一关会重新开始，路标仅保留在本次游玩中，完整关卡完成记录保存到本机。

「追光」光球沿真实四维路线移动，在两个停靠点等待玩家，不代替玩家触发路标。「漂游之间」和「错峰门廊」周期均为 8 秒。移动实体的扫掠体也参加碰撞，包含从切片外进入的情况；若将碰到玩家，则暂停运动时钟，玩家离开后继续，不推着视角走。章节地图打开、失焦或追踪不可用时暂停运动与讲解。

## 并列立体讲解与旁白

九个教程关共有 **41 个手动步骤**。前三课展示二维角色如何借助旋转探索三维；辨认与运动六课均并列放置「二维观察三维」与「三维观察四维」。左边完整三维线框供外部观察，亮色截面是二维角色实际接触的部分；右边只显示四维物体的真实三维截面。运动两侧共用时间与比例。

每步动画播放一次后冻结，等待玩家选择下一步；可以从不同角度观察、返回或重播。进入实际关卡前点击「开始探索」，并按当前头显位姿重新设置关卡起点。

## 操作

- 张开任一只手、掌心背向自己，左右横移控制 θ。
- 右掌朝自己唤出紧凑面板，左食指接近按钮后点按；按钮有独立的悬停/按下深度动效。
- 游戏面板保留 θ 归零、参考平面（挑战关为提示）、重试/返回路标/下一关、章节地图四项。

| 按键 | 动作 |
| --- | --- |
| WASD | 沿当前切片地面移动；辨认章实际观察保持原点 |
| Q / E | 唯一的切片角度 θ |
| M | 调试面板 |
| L | 章节树形地图 |
| 1 / 2 / 3（树页） | 查看移动 / 辨认 / 运动章节 |
| 1–6（章页） | 选择当前章节内对应的已解锁关卡 |
| Esc | 关卡页 → 章节树 → 返回游戏 |
| [ / ] | 章页切换章节；树页选择节点 |
| Tab / Shift+Tab / Enter | 选择前后按钮 / 执行 |
| R 或 P | θ 归零；讲解时重播当前步骤 |
| H | 教程回看讲解；挑战按需增加一级提示 |
| V | 参考平面；挑战显示提示 |
| T | 重试 / 返回路标；讲解从头开始 |
| N 或 Space | 讲解下一步；关卡完成后下一关；章节完成后返回地图 |
| B | 讲解上一步 |

模拟器需点亮左侧「键盘＋笔」输入按钮，确保按键传入游戏。数字键现在按当前页面解释，不再使用旧的全局 7–9 选关方式。真实手势与键盘提供对应操作入口。

## 构建与运行

JDK 21、Android SDK 35 / Build Tools 35.0.0、NDK 28.2.13676358、CMake 3.22.1。OpenXR Loader 为 1.1.65，最低 Android API 35、ARM64，需 PICO OS 6 / Swan 的 OpenXR、OpenGL ES 3 与 OPAQUE 双眼运行时。

```sh
./gradlew :app:testDebugUnitTest :app:assembleDebug :app:lintDebug
pico-cli app install app/build/outputs/apk/debug/app-debug.apk --replace
pico-cli app launch com.fourthward.game
```

`local.properties` 保存本机 SDK 路径并排除提交。语音生成需本地 `FISH_API_KEY` 与 macOS `afconvert`；无需在运行游戏时联网。
